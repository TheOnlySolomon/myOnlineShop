# CloverCali Homepage

This is the responsive homepage recreated from the supplied CloverCali prototype.

## Files

- `index.html` — homepage structure
- `style.css` — responsive styling and exact prototype colour palette
- `script.js` — product carousel + contact form demo
- `images/` — place your actual Figma-exported images here

## Add your Figma assets

Replace these files:

- `images/logo.png`
- `images/hero.jpg`
- `images/drop-1.jpg`
- `images/drop-2.jpg`
- `images/drop-3.jpg`

The CSS will automatically size them correctly.

## Run it

Open the folder in VS Code and use Live Server, or simply open `index.html` in your browser.

Recommended VS Code extension:
Live Server by Ritwick Dey

## Main colours sampled from the prototype

Main background: `#0B5D3B`
Card green: `#126B48`
Accent green: `#087A4B`
Footer green: `#378E63`

The page uses a maximum desktop content width of 1180px and scales down through tablet and mobile breakpoints.
